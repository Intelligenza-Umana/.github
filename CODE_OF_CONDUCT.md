# Code of conduct

Treat contributors respectfully, welcome different experience levels, and criticize ideas and code rather than people. Harassment, discrimination, threats, and disclosure of private information are not acceptable.

Report conduct concerns privately to intelligenzaumana.lab@gmail.com. Maintainers may remove harmful content or restrict participation proportionately. See the [foundation code of conduct](https://github.com/fabiozagaria/intelligenza-umana/blob/main/community/CODE_OF_CONDUCT.md).
