# Contributing to Intelligenza Umana

**Human intelligence. Artificial assistance.** We build software by understanding the problem, reasoning from evidence, checking the code and keeping human responsibility clear. Read our [manifesto](https://github.com/fabiozagaria/intelligenza-umana/blob/main/MANIFESTO.md) and [engineering standard](https://github.com/fabiozagaria/intelligenza-umana/blob/main/docs/ENGINEERING_STANDARD.md) before proposing substantial changes.

Anyone may read public repositories, discuss ideas in public issues and contribute through a fork and pull request. Organization membership is not required to propose a change. Maintainers review contributions and decide whether to merge them; a pull request is not accepted until an authorized maintainer approves it.

Direct write access and maintainer actions, including approving and merging contributions, are reserved for people explicitly admitted to the organization or granted the relevant repository role. To request membership, email [intelligenzaumana.lab@gmail.com](mailto:intelligenzaumana.lab@gmail.com) with your GitHub username, the projects or areas you are interested in, and a short note about how you would like to participate. The founder reviews requests based on project needs and the community principles.

AI assistance is welcome. Contributors remain responsible for understanding, checking and explaining their changes. Experience level is not a barrier; ask questions and request clarification at any point.

Never publish secrets or exploitable vulnerability details in public issues. See the [security policy](https://github.com/Intelligenza-Umana/.github/blob/main/SECURITY.md).
