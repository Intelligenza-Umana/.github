# Contributing to Intelligenza Umana

Everyone is welcome to contribute, regardless of experience. Membership is not required.

- Find an open issue in the relevant project or propose a concrete improvement.
- Comment before starting substantial work to avoid duplication.
- Fork the repository, create a focused branch, and submit a pull request with verification results and known limitations.
- Understand and review any AI-generated work; disclose material AI assistance.
- Respond respectfully to review. Maintainers decide whether to merge as capacity allows.

Read the [full contribution guide](https://github.com/fabiozagaria/intelligenza-umana/blob/main/CONTRIBUTING.md) and [engineering standard](https://github.com/fabiozagaria/intelligenza-umana/blob/main/docs/ENGINEERING_STANDARD.md). Never publish secrets or exploitable vulnerabilities in issues.
