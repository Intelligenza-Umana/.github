# Intelligenza Umana

**Human intelligence. Artificial assistance.**

Intelligenza Umana is an independent engineering and applied research initiative building useful, reliable, understandable and verifiable software. AI can assist the work; people remain responsible for understanding, decisions and review.

Our interests include backend engineering, cybersecurity, data integrity, algorithms, distributed systems, AI reliability and developer tools. The initiative is currently maintained by its founder and is open to contributions.

## Projects

- [Learning Ledger](https://github.com/fabiozagaria/iu-learning-ledger) — a local evidence ledger for AI-assisted learning.
- [Spring Security Advisor](https://github.com/fabiozagaria/iu-spring-security-advisor) — a Spring Boot security review assistant; its score is not a security certification.
- [Project Lifecycle Skill](https://github.com/fabiozagaria/iu-project-lifecycle-skill) — a prototype for maintaining project context and handoffs.

Projects have independent repositories and maturity levels. See the [official project registry](https://github.com/fabiozagaria/intelligenza-umana/blob/main/docs/PROJECT_REGISTRY.md) for canonical URLs and status. A project label is not a cryptographic signature; release verification is still being developed.

## Contribute

Start with the [foundation](https://github.com/fabiozagaria/intelligenza-umana), [contribution guide](https://github.com/fabiozagaria/intelligenza-umana/blob/main/CONTRIBUTING.md) and [engineering standard](https://github.com/fabiozagaria/intelligenza-umana/blob/main/docs/ENGINEERING_STANDARD.md). Open an issue in the relevant repository to discuss a concrete problem. No seniority threshold applies; review depends on available capacity.

For vulnerability reports, please follow the [private reporting guidance](https://github.com/fabiozagaria/intelligenza-umana/blob/main/SECURITY.md). General enquiries: [intelligenzaumana.lab@gmail.com](mailto:intelligenzaumana.lab@gmail.com).
