# Intelligenza Umana

**Human intelligence. Artificial assistance.**

We are an independent engineering and applied research initiative building software that is useful, reliable, understandable and verifiable. We use AI to extend human capabilities while keeping understanding, judgment and responsibility in human hands.

## How we think about software

We start with a real problem and make the reasoning visible: define constraints, examine alternatives, build the smallest useful solution, and verify its behavior. We treat AI output as untrusted until a person has understood and reviewed it. Tests support engineering judgment; they do not prove absolute security or correctness. We state uncertainty and limitations plainly.

Our work explores backend engineering, cybersecurity, data integrity, algorithms, distributed systems, AI reliability and developer tools. Read our [manifesto](https://github.com/fabiozagaria/intelligenza-umana/blob/main/MANIFESTO.md) and [engineering standard](https://github.com/fabiozagaria/intelligenza-umana/blob/main/docs/ENGINEERING_STANDARD.md).

## Projects

- [Learning Ledger](https://github.com/fabiozagaria/iu-learning-ledger) — a local evidence ledger for AI-assisted learning.
- [Spring Security Advisor](https://github.com/fabiozagaria/iu-spring-security-advisor) — a Spring Boot security review assistant; its score is not a security certification.
- [Project Lifecycle Skill](https://github.com/fabiozagaria/iu-project-lifecycle-skill) — a skill for maintaining project context and handoffs; native host workflows remain unverified.
- [IU Model Router](https://github.com/fabiozagaria/iu-model-router) — an early model-routing skill for coding agents; native host behavior is not yet verified.

Projects have independent repositories and maturity levels. See the [official project registry](https://github.com/fabiozagaria/intelligenza-umana/blob/main/docs/PROJECT_REGISTRY.md) for canonical URLs and status. A project label is not a cryptographic signature; release verification is still being developed.

## Participate

Public repositories are open to read. Anyone may discuss work, fork a project and submit a pull request. Maintainers review and approve changes before they are merged. Direct write access and maintainer duties are reserved for admitted organization members or people explicitly granted repository permissions.

To request organization membership, email [intelligenzaumana.lab@gmail.com](mailto:intelligenzaumana.lab@gmail.com) with your GitHub username, interests and a short note about how you would like to help. No particular seniority is required. AI assistance is welcome; human understanding and responsibility remain essential.

For vulnerability reports, follow the [private reporting guidance](https://github.com/fabiozagaria/intelligenza-umana/blob/main/SECURITY.md). General enquiries: [intelligenzaumana.lab@gmail.com](mailto:intelligenzaumana.lab@gmail.com).
