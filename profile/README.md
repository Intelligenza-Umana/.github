# Intelligenza Umana

**Human intelligence. Artificial assistance.**

Intelligenza Umana is an independent engineering and applied research initiative building useful, reliable, understandable and verifiable software. AI can assist the work; people remain responsible for understanding, decisions and review.

Our interests include backend engineering, cybersecurity, data integrity, algorithms, distributed systems, AI reliability and developer tools. The initiative is currently maintained by its founder and is open to contributions.

## Projects

- [Learning Ledger](https://github.com/Intelligenza-Umana/iu-learning-ledger) — a local evidence ledger for AI-assisted learning.
- [Spring Security Advisor](https://github.com/Intelligenza-Umana/iu-spring-security-advisor) — a Spring Boot security review assistant; its score is not a security certification.
- [Project Lifecycle Skill](https://github.com/Intelligenza-Umana/iu-project-lifecycle-skill) — a skill for maintaining project context and handoffs; native host workflows remain unverified.
- [IU Model Router](https://github.com/Intelligenza-Umana/iu-model-router) — an early model-routing skill for coding agents; native host behavior is not yet verified.

Projects have independent repositories and maturity levels. See the [official project registry](https://github.com/Intelligenza-Umana/intelligenza-umana/blob/main/docs/PROJECT_REGISTRY.md) for canonical URLs and status. A project label is not a cryptographic signature; release verification is still being developed.

## Contribute

Join the [Intelligenza Umana Discord community](https://discord.gg/fMRBCNgHb) to meet contributors and follow community discussions.

Start with the [foundation](https://github.com/Intelligenza-Umana/intelligenza-umana), [contribution guide](https://github.com/Intelligenza-Umana/intelligenza-umana/blob/main/CONTRIBUTING.md) and [engineering standard](https://github.com/Intelligenza-Umana/intelligenza-umana/blob/main/docs/ENGINEERING_STANDARD.md). Open an issue in the relevant repository to discuss a concrete problem. No seniority threshold applies; review depends on available capacity.

For vulnerability reports, please follow the [private reporting guidance](https://github.com/Intelligenza-Umana/intelligenza-umana/blob/main/SECURITY.md). General enquiries: [intelligenzaumana.lab@gmail.com](mailto:intelligenzaumana.lab@gmail.com).

## Find your first contribution

Students, junior developers and experienced engineers are welcome. You do not need to be an organization member to contribute.

- [Good first issues](https://github.com/search?q=org%3AIntelligenza-Umana+is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22&type=issues): small, approachable tasks.
- [Help wanted](https://github.com/search?q=org%3AIntelligenza-Umana+is%3Aissue+is%3Aopen+label%3A%22help+wanted%22&type=issues): testing, documentation and engineering tasks.
- [Propose an experiment](https://github.com/Intelligenza-Umana/intelligenza-umana/issues/5): bring a concrete problem or idea.

Choose an issue, comment with your intended approach, and discuss scope before submitting a pull request. Contributions may include documentation, reproducible tests, bug reports and code. Review is voluntary and depends on maintainer availability. If you know someone who might enjoy a task, share its issue link with them.
